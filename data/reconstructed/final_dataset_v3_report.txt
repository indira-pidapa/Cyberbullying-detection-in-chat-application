FINAL DATASET V3 — RECONSTRUCTION AND CLEANUP REPORT
=====================================================

Policy applied:
1. Rebuilt from all 10 supplied source CSVs using the source combination and
   basic row filtering already reproduced in final_dataset_v2_candidate.csv.
2. Did NOT apply the global slang expansion.
3. Normalized text for exact duplicate/conflict detection using lowercase,
   leading/trailing trim, and collapsing repeated whitespace. Original
   clean_text spelling/casing is retained in the output.
4. Conflicting-label text groups were excluded from the training candidate
   and all original rows for those groups were saved to a separate quarantine.
5. Same-text, same-label duplicates were collapsed to one record globally.
   The source column preserves all contributing source names, separated by ';'.
6. Hinglish2's 25,000 repeated rows therefore contribute only unique messages
   (its 40 unique messages are retained unless a message is quarantined for
   conflicting labels).
7. Sample weights were recomputed after deduplication and conflict exclusion:
   inverse-frequency class base weight multiplied by the maximum original
   source multiplier among the contributing sources. The individual source
   multipliers are retained in source_multipliers.

Original candidate rows: 254,303

Important limitations:
- This file is a cleaned dataset candidate, not yet a train/validation/test split.
- Near-duplicates and paraphrases have not been detected.
- Exact duplicate removal does not guarantee absence of semantic leakage.
- Conflicting-label groups were excluded rather than manually relabelled.
- Source-level class balance and synthetic-data influence must be reviewed.
- The max-source-multiplier rule is explicit and conservative in record count,
  but should be approved before training; it preserves the strongest existing
  source emphasis for merged records.
